# Scribd downloader

## Installation

Requires Python 3.13+.

```sh
uv tool install git+https://github.com/lain804/scribd-downloader.git
```

Or with pip:

```sh
pip install git+https://github.com/lain804/scribd-downloader.git
```

## Usage

```sh
scribd-downloader <scribd-url>
scribd-downloader --help
```
